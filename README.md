# বাসা খুঁজি — To-Let Full-Stack Application

**বাসা খুঁজি (To-Let)** হলো সাতক্ষীরা–খুলনা অঞ্চলের সরাসরি বাড়িওয়ালা ও ভাড়াটিয়াদের সংযোগকারী একটি আধুনিক, রেসপন্সিভ এবং পূর্ণাঙ্গ ফুল-স্ট্যাক রেন্টাল হাউস পোর্টাল।

মূল জাভাস্ক্রিপ্ট/লোকালস্টোরেজ ভিত্তিক ডেমো প্রজেক্ট থেকে সম্পূর্ণ রূপান্তর করে এটিকে একটি আধুনিক **React 18 + Vite + TypeScript + Node.js + Express + Prisma ORM + SQLite** ফুল-স্ট্যাক আর্কিটেকচারে পুনর্গঠন করা হয়েছে।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **বাংলা-ফার্স্ট ইউজার ইন্টারফেস (Bengali-First UI):** সম্পূর্ণ বাংলা ইন্টারফেস, বাংলা সংখ্যা রূপান্তর (`০-৯`), বাংলা কারেন্সি ও এরিয়া ফরম্যাটিং।
- **ইন্টারেক্টিভ খুলনা সিটি ম্যাপ ও GIS সিস্টেম (Interactive Khulna City Map):**
  - **React Leaflet + Leaflet + OpenStreetMap** সমন্বিত সম্পূর্ণ দেশীয় ও পলিসি-সম্মত ম্যাপিং ইঞ্জিন।
  - খুলনার সকল ৩১টি ওয়ার্ড (KCC Ward 1-31), সোনাডাঙ্গা, খালিশপুর, দৌলতপুর, বয়রা, শিববাড়ী, নিরালা, গল্লামারী, টুটপাড়া সহ ৫৯+ ভেরিফায়েড লোকেশন ডাটাবেস।
  - কাস্টম SVG প্রাইস-ব্যাজ মার্কার পিন (ভাড়ার পরিমাণ সহ মার্কার)।
  - মার্কার পপআপে প্রপার্টির ছবি, মাসিক ভাড়া, বেডরুম, তলা ও বিস্তারিত বাটন।
  - ৩ ধরনের ভিউ মোড: **তালিকা ভিউ (List View)**, **স্প্লিট ভিউ (Split View)**, ও **ম্যাপ ভিউ (Map View)**।
  - পোস্ট করার সময় ইন্টারেক্টিভ **ম্যাপ লোকেশন পিকার (Draggable Pin)** ও গোপনীয়তার জন্য **আনুমানিক/পাবলিক পিন (Approximate Pin)** অপশন।
  - বাংলা ও ইংরেজিতে কেস-ইনসেনসিটিভ রিয়েল-টাইম অটোকমপ্লিট সার্চ ও অ্যালাইয়াস সাপোর্ট।
- **আসল ব্যাকএন্ড ও ডাটাবেস পারসিস্টেন্স:** `localStorage` এর পরিবর্তে আসল **SQLite** ডাটাবেস ও **Prisma ORM** এর মাধ্যমে স্থায়ী ডাটা সংরক্ষণ।
- **শক্তিশালী সার্চ ও ফিল্টারিং:**
  - নির্দিষ্ট এলাকা বা সব এলাকা অনুসন্ধান
  - কেসিসি ওয়ার্ড ভিত্তিক ফিল্টারিং
  - ভিউপোর্ট বাউন্ডিং বক্স ফিল্টারিং (`bounds`)
  - সর্বোচ্চ মাসিক ভাড়ার সীমা নির্ধারণ
  - সর্বনিম্ন প্রয়োজনীয় রুমের সংখ্যা
  - নির্দিষ্ট তলা (Floor) নির্বাচন
  - পরিবারের সদস্য ধারণক্ষমতা (Capacity)
  - ভাড়াটিয়া ধরন (ফ্যামিলি, ব্যাচেলর বা যে কেউ)
- **সর্টিং সুবিধা:** সর্বনিম্ন ভাড়া আগে (`rent`) অথবা নতুন বিজ্ঞাপন আগে (`new`)।
- **নিরাপদ বিজ্ঞাপন মালিকানা ও ডিলিট টোকেন (Listing Ownership & Deletion Security):**
  - সাধারণ ব্যবহারকারীদের জন্য রেজিস্ট্রেশনের ঝামেলা ছাড়াই বিজ্ঞাপন পোস্ট করার সুবিধা।
  - পোস্ট তৈরির সাথে সাথে ব্যাকএন্ডে ক্রিপ্টোগ্রাফিকালি শক্তিশালী **Deletion Token** তৈরি হয়।
  - ডাটাবেসে শুধুমাত্র টোকেনের নিরাপদ **SHA-256 Hash** সংরক্ষিত থাকে।
  - বিজ্ঞাপনদাতার ব্রাউজারে টোকেনটি সংরক্ষিত হয়; শুধুমাত্র সঠিক টোকেন থাকলেই "আমার পোস্ট মুছুন" অপশনটি কাজ করে।
  - পাবলিক API রেসপন্সে কখনোই ডিলিট টোকেন বা হ্যাশ উন্মুক্ত করা হয় না।
- **রুমের ছবি আপলোড ও প্রসেসিং:**
  - Multer ও সিকিউর ইউনিক ফাইলনেম ভিত্তিক আপলোড সিস্টেম (`backend/uploads/`)।
  - ক্লায়েন্ট-সাইড ক্যানভাস ইমেজ কম্প্রেশন (ব্যান্ডউইথ সাশ্রয়ের জন্য)।
  - ছবি না থাকলে স্বয়ংক্রিয় মূল ডিজাইনের SVG ব্লুপ্রিন্ট প্লেসহোল্ডার।
- **কল ও কপি অপশন:** সরাসরি কল করার সুবিধা (`tel:...`) এবং এক ক্লিকে ফোন নম্বর ক্লিপবোর্ডে কপি করার সুবিধা।
- **ডার্ক মোড ও থিম টগল:** সিস্টেম ডার্ক মোড স্বয়ংক্রিয়ভাবে সনাক্তকরণ এবং ম্যানুয়াল থিম টগল (লাইট/ডার্ক/সিস্টেম)।
- **এক ক্লিকে ফুল-স্ট্যাক রান:** রুট ফোল্ডার থেকে শুধুমাত্র `npm run dev` দিয়ে ব্যাকএন্ড ও ফ্রন্টএন্ড একসাথে চালু করার সুবিধা।

## 🛠️ প্রযুক্তিগত কাঠামো (Technology Stack)

| স্তর | প্রযুক্তি | বিবরণ |
| :--- | :--- | :--- |
| **Frontend** | React 18, Vite, TypeScript | দ্রুতগতির SPA, কম্পোনেন্ট-ভিত্তিক আর্কিটেকচার |
| **Interactive Map** | Leaflet, React Leaflet, OpenStreetMap | খুলনা সিটির ইন্টারেক্টিভ ম্যাপ ও কাস্টম প্রাইস মার্কার |
| **Icons & UI** | Lucide React, Modular CSS | প্রিমিয়াম ভেক্টর আইকন ও ক্লাসিক গ্রিন থিম |
| **Backend** | Node.js, Express.js, TypeScript | RESTful API আর্কিটেকচার |
| **Database** | SQLite, Prisma ORM | লোকাল ডেভেলপমেন্টের জন্য শূন্য কনফিগারেশনের রিলেশনাল ডাটাবেস |
| **Validation** | Zod | রিকোয়েস্ট বডি এবং কোয়েরি প্যারামিটার ভ্যালিডেশন |
| **File Upload** | Multer | নিরাপদ ইমেজ আপলোড ও ফিল্টারিং (JPEG, PNG, WebP) |
| **Task Runner** | Concurrently, npm workspaces | রুট ফোল্ডার থেকে প্যারালাল ব্যাকএন্ড-ফ্রন্টএন্ড ম্যানেজমেন্ট |

## ⚡ ইনস্টলেশন ও রানিং গাইড (Getting Started)

### পূর্বশর্ত:
- **Node.js**: v18.0.0 বা তার বেশি (Node v20/v24 রেকমেন্ডেড)
- **Windows 11 / Linux / macOS**

### ধাপ ১: ডিপেন্ডেন্সি ইনস্টল করুন
প্রজেক্টের রুট ডিরেক্টরিতে টার্মিনাল খুলে চালান:
```bash
npm install
```
*(এটি রুট, ফ্রন্টএন্ড এবং ব্যাকএন্ডের সকল ডিপেন্ডেন্সি ইনস্টল করবে এবং Prisma ক্লায়েন্ট জেনারেট করবে।)*

### ধাপ ২: ডাটাবেস সেটআপ ও সিডিং
লোকাল SQLite ডাটাবেস তৈরি, খুলনা লোকেশন এবং ডেমো প্রপার্টি সিড করতে চালান:
```bash
npm run db:setup
```

### ধাপ ৩: ফুল-স্ট্যাক অ্যাপ্লিকেশন চালু করুন
একক কমান্ডে ব্যাকএন্ড এবং ফ্রন্টএন্ড উভয়ই চালু করুন:
```bash
npm run dev
```

চালু হওয়ার পর ব্রাউজারে প্রবেশ করুন:
- **Frontend App:** [http://localhost:5173](http://localhost:5173)
- **Backend API:** [http://localhost:5000](http://localhost:5000)
- **API Health Check:** [http://localhost:5000/api/health](http://localhost:5000/api/health)

## 📜 প্রয়োজনীয় কমান্ডসমূহ (Available Scripts)

| কমান্ড | বিবরণ |
| :--- | :--- |
| `npm run dev` | ব্যাকএন্ড (`:5000`) ও ফ্রন্টএন্ড (`:5173`) একসাথে কনকারেন্টলি চালু করে |
| `npm run dev:frontend` | শুধুমাত্র Vite ফ্রন্টএন্ড সার্ভার চালু করে |
| `npm run dev:backend` | শুধুমাত্র Express ব্যাকএন্ড সার্ভার চালু করে |
| `npm run build` | ব্যাকএন্ড ও ফ্রন্টএন্ড উভয়ের জন্য অপ্টিমাইজড প্রোডাকশন বান্ডেল তৈরি করে |

## 🗺️ খুলনা লোকেশন ডাটাবেস ও ম্যাপিং সিস্টেম (Khulna GIS Architecture)

1. **হায়ারার্কিক্যাল লোকেশন মডেল:**
   - **দেশ:** বাংলাদেশ (Bangladesh)
   - **বিভাগ:** খুলনা বিভাগ (Khulna Division)
   - **জেলা:** খুলনা জেলা (Khulna District)
   - **সিটি:** খুলনা সিটি কর্পোরেশন (KCC)
   - **ওয়ার্ড:** ওয়ার্ড ০১ থেকে ওয়ার্ড ৩১ (সবগুলো বাস্তবসম্মত জিপিএস কোঅর্ডিনেট সহ)
   - **এলাকা / মহল্লা:** সোনাডাঙ্গা, বয়রা, খালিশপুর, দৌলতপুর, শিববাড়ী, নিরালা, ময়লাপোতা, গল্লামারী, টুটপাড়া, শেখপাড়া ইত্যাদি।
   - **ল্যান্ডমার্ক ও মোড়:** খুলনা বিশ্ববিদ্যালয়, কুয়েট, সোনাডাঙ্গা বাস টার্মিনাল, শিববাড়ী মোড়, রূপসা ট্রাফিক মোড় ইত্যাদি।
2. **সার্চ অপ্টিমাইজেশন:**
   - প্রতিটি লোকেশনে বিকল্প বানান ও অ্যালাইয়াস সংরক্ষিত রয়েছে (যেমন: `Ward 24`, `Nirala`, `নিরালা`, `Nirala R/A`)।
   - কেস-ইনসেনসিটিভ ফিল্টারিং ও ডিবাউন্সড সার্চ সিস্টেম।
3. **প্রাইভেসি প্রোটেকশন (`isApproximatePin`):**
   - বাড়িওয়ালারা চাইলে বিজ্ঞাপন প্রকাশের সময় তাদের বাসার সঠিক পিন উন্মুক্ত না করে পাবলিক ভিউতে আনুমানিক/এরিয়া-লেভেল পিন হিসেবে দেখাতে পারেন।
4. **মার্কার ও কার্ড সিঙ্ক:**
   - ম্যাপে যেকোনো মার্কার ক্লিক করলে সংশ্লিষ্ট প্রপার্টির তথ্য ও পপআপ প্রদর্শিত হয়; অনুরূপভাবে কার্ডে ক্লিক করলে ম্যাপ স্বয়ংক্রিয়ভাবে মার্কারে ফোকাস করে।

## 🔒 সিকিউরিটি ও ডিলিট টোকেন সিস্টেম (Security Architecture)

1. **টোকেন জেনারেশন:** কোনো ব্যবহারকারী যখন `POST /api/listings` কল করেন, ব্যাকএন্ড একটি ৩২-বাইটের ক্রিপ্টোগ্রাফিক র‍্যান্ডম স্ট্রিং তৈরি করে।
2. **হ্যাশ সংরক্ষণ:** টোকেনটিকে ডাটাবেসে সরাসরি সেভ না করে তার SHA-256 হ্যাশ সংরক্ষণ করা হয়।
3. **এককালীন রিটার্ন:** আসল টোকেনটি শুধুমাত্র বিজ্ঞাপন তৈরীর রেসপন্সে একবার প্রদান করা হয় এবং ফ্রন্টএন্ডের `localStorage`-এ সেভ হয়।
4. **কনস্ট্যান্ট-টাইম ভেরিফিকেশন:** বিজ্ঞাপন মোছার সময় পাঠানো টোকেনটিকে `crypto.timingSafeEqual` দিয়ে মিলিয়ে যাচাই করা হয়, যা টাইমিং অ্যাটাক প্রতিরোধ করে।
5. **ডেমো পোস্ট সুরক্ষা:** মূল ৬টি ডেমো প্রপার্টি `isDemo: true` ফ্ল্যাগ দিয়ে সুরক্ষিত, যা সাধারণ ব্যবহারকারী দ্বারা ডিলিট হওয়া প্রতিরোধ করে।

## 📌 সীমাবদ্ধতা এবং ভবিষ্যৎ উন্নয়ন পরিকল্পনা (Limitations & Future Roadmap)

### বর্তমান সীমাবদ্ধতা:
- **ভেরিফায়েড রাস্তা ও গলি:** এই ডাটাবেসে খুলনার সকল ৩১টি কেসিসি ওয়ার্ড, প্রধান প্রধান এলাকা, মহল্লা এবং গুরুত্বপূর্ণ মোড় ও ল্যান্ডমার্ক অন্তর্ভুক্ত করা হয়েছে। খুলনার প্রতিটি ছোট অলি-গলি (All alleys) এতে অন্তর্ভুক্ত করার দাবি করা হয়নি, তবে ব্যবহারকারীরা বাসা পোস্ট করার সময় তাদের নির্দিষ্ট রোড বা গলির নাম কাস্টম ঠিকানা হিসেবে যুক্ত করতে পারেন এবং ম্যাপে সঠিক পিন নির্বাচন করতে পারেন।
- **ডিভাইস-নির্দিষ্ট টোকেন:** ডিলিট টোকেন ব্রাউজারের লোকাল স্টোরেজে সংরক্ষিত থাকায় এক ব্রাউজার বা ডিভাইস থেকে পোস্ট তৈরি করলে অন্য ডিভাইস থেকে সরাসরি মুছা যাবে না (যদি না ম্যানুয়ালি টোকেন শেয়ার করা হয়)।
- **এসএমএস ভেরিফিকেশন নেই:** ফোন নম্বর সঠিকভাবে ভ্যালিডেট করা হয় (বাংলাদেশি ১১ সংখ্যা), তবে রিয়েল-টাইম ওটিপি (OTP) ভেরিফিকেশন অন্তর্ভুক্ত করা হয়নি।

### ভবিষ্যৎ উন্নয়ন পরিকল্পনা:
- ব্যবহারকারী ও বাড়িওয়ালাদের জন্য সম্পূর্ণ ফোন নম্বর ভিত্তিক ওটিপি (OTP) বা ইমেইল অ্যাকাউন্ট অথেনটিকেশন।
- একাধিক ছবি ও ভিডিও আপলোড গ্যালারি।
- বাড়িওয়ালার সাথে সরাসরি ইন-অ্যাপ চ্যাট করার ফিচার।
